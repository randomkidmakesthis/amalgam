## Correction 2026-11-26: VICTORY_CARD_BUFFERS_MB=2048 REJECTED

Adopted on run-73/78 because the out-of-memory fallback stopped firing and "made again" fell from 7 GB to 0.7 GB. The user then saw MORE missing visuals and slower texture streaming (run-84, shown).
